# Kanji Writing Prototype

Мини-прототип интерактивной карточки для тренировки написания кандзи.

Открой `index.html` в браузере. Сейчас карточка поддерживает один кандзи: `日`.

Что уже есть:

- поле для рисования от руки;
- разбиение рисунка на отдельные штрихи;
- кнопки очистки, отмены, проверки и переворота;
- реальные штрихи из KanjiVG для показа правильного порядка;
- примерная проверка количества штрихов, направления, формы и положения;
- оборот карточки со значением, онъёми, кунъёми и примерами слов.

Данные:

- `../data/cards.json` — список карточек, которые нужно собрать;
- `../data/kanjivg/065e5.svg` — исходный SVG KanjiVG для `日`;
- `../generated/kanji-data.json` — компактные данные для будущего генератора Anki;
- `../generated/kanji-data.js` — те же данные как браузерный скрипт, чтобы карточка открывалась без локального сервера.

Чтобы добавить следующий кандзи:

1. Добавить запись в `../data/cards.json`.
2. Запустить из корня проекта:

   ```sh
   node scripts/extract_kanjivg.js
   ```

Скрипт сам скачает недостающие SVG из KanjiVG в `data/kanjivg/` и пересоберет `generated/kanji-data.json` и `generated/kanji-data.js`.

KanjiVG распространяется под Creative Commons Attribution-Share Alike 3.0. Атрибуция добавлена в `../ATTRIBUTION.md`.
