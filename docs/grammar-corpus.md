# Банк предложений и пакетный конвейер грамматики

Полный курс из 526 готовых уроков **пока не подготовлен**. Этот пакет обработал
все 526 исходных правил и создал воспроизводимую очередь кандидатов/ревью,
нормализованный банк и безопасный шлюз публикации. Автоматическое совпадение
по морфологии не заменяет смысловую проверку и не создаёт оцениваемое задание.

## Источники и фиксация

Tatoeba: официальная пакетная выгрузка 2026-10-10, получена 2026-10-13. Скачаны
шесть файлов: японские/английские/русские detailed sentences, links, Japanese
indices и CC0 sentences. URLs, Last-Modified, размеры и SHA-256 — в
[corpus/snapshot.json](../tools/grammar/corpus/snapshot.json). Японский оригинал,
настоящий ID, владелец/атрибуция, прямая связанная переводная запись и её ID,
лицензия и ссылка сохранены. Нет выдуманных Tatoeba ID. Аудио не импортировалось.

Каждый источник/перевод лицензирован отдельно: CC BY 2.0 FR либо CC0 1.0,
только если его ID присутствует в официальном CC0-файле. Оригинальные примеры
OpenJLPT — CC BY-SA 4.0, commit 0d1d3410bec90bd4098a7c72de820543cb4f707c.
Оригинальная грамматика Nihongo Mono — MIT, © 2026 Stefanus Ndaru Wedhatama,
commit ec0ba4a0ce1611c568b0e4f8a223eb8029249a25. Для 355 правил найдены точные
уникальные title/slug либо прежние явно заданные сопоставления; они остаются
кандидатными привязками. Сторонние словари Nihongo Mono не импортированы.
Лицензии, copyright и границы источников сохранены в corpus/NOTICE.md и Bundle.

SudachiPy 0.6.11 + SudachiDict-core 20250129 используются только при подготовке.
Сохраняются surface, lemma, POS, тип/форма спряжения, reading, OOV и позиции
UTF-8. Прочтения — предложения для проверки: 私 не автоматически объявляется
わたくし; неоднозначные/OOV токены отмечаются. Словарь, Python и полные выгрузки
не входят в iOS. Данные анализатора не служат доказательством значения правила.

## Обработка всего корпуса

Каждый уровень обработан отдельным пакетом, с coverage/review checkpoint.
Профили есть у всех 526 ID. Поиск использует surface probes и последовательности
lemma/POS, а для выбранных глагольных конструкций — явные ограничения соседних
токенов. Формы с ている ищутся через начальные формы, а не только буквальную строку.
Japanese indices сохранены как независимые исходные аннотации словоупотребления;
индексированные предложения предпочтительны при отборе. Ни indices, ни lemma
не утверждают, что найден именно нужный оттенок значения. Неподдержанные формы,
неоднозначный регистр/отрицание/субъект требуют отдельной разметки.

На этом этапе отобрано 2 987 уникальных кандидатов Tatoeba. Из OpenJLPT и
Nihongo Mono подготовлено 2 215 уникальных исходных предложений. После объединения
получено 5 201 уникальное предложение и 5 483 кандидатные связи с правилами.
Среднее: 10,42 кандидата на правило. Минимум: 2. У 445 правил есть хотя бы пять
кандидатов; у 81 — меньше пяти. **Кандидаты не являются готовыми контекстами.**

## Нормализация и обучение

GrammarSentenceBank хранит исходный японский текст один раз. В resource rules
вместо копий examples/exercises находятся exampleReferences и exerciseTemplateIDs.
Повторяющиеся тексты условий/ответов/пояснений интернированы; шаблоны ссылаются
на sentence/text IDs. GrammarDataLoader разрешает ссылки на своём actor и
возвращает существующие GrammarRule/GrammarExercise. Legacy inline JSON остаётся
декодируемым. Исходные 1526 примеров, 526 ID и значения OpenJLPT восстановимы точно.

В Bundle опубликованы 1 595 уникальных предложений из прежнего материала и
83 компактных шаблона. Непроверенные Tatoeba-кандидаты/морфология/review packets
остаются в tools/grammar/corpus, вне app resources. Повторного загрузчика/SRS/
GrammarExerciseEngine не создано. Тренировка не делает запросов к источникам.

Границы смысловых блоков не равны всем токенам. У кандидатов segments пусты,
пока автор/ревьюер не задаст подходящие составляющие. Прежние авторские сборки
имеют явные UTF-8 границы и допустимые порядки; они полностью восстанавливают текст.
Случайное удаление токенов и случайные неправильные варианты не используются.

GrammarExerciseEngine избегает дубликатов sentenceID внутри попытки.
GrammarMixedSessionViewModel предпочитает другой sentenceID следующему вопросу,
сохраняя выбор правил по FSRS/cooldown. Между повторениями действует прежняя
детерминированная ротация по attempts; точного постоянного журнала каждого
увиденного предложения нет, новая запись в review-memory.json не добавлялась.
Одна завершённая попытка правила по-прежнему создаёт одну FSRS-оценку; существующие
Learning/Relearning/Review/Undo/лимиты/история и ключи не менялись.

Фуригана отображается прежними FuriganaText/FuriganaParser/showExampleFurigana.
У 78 из 83 прежних заданий (93,98%) есть хотя бы один явно размеченный текст.
Это не означает чтение каждого иероглифа/варианта. Новые Sudachi-proposals не
публикуются без проверки; reading tasks подавляют ruby. Оригинальные bytes сохраняются.

Типы прежних заданий: formProduction — 3; fillBlank — 20; transformSentence,
assembleSentence, chooseContext, correctError, distinguishMeaning,
understandSentence — по 10. Новых оцениваемых упражнений из Tatoeba — **0**.

## Ревью и честные ограничения

review.json разделяет проверку предложения/перевода, конкретного употребления
правила и упражнения. Публикация требует reviewer, объяснение смысла/ограничений,
точные targetSpan/segments, русский перевод, ключи/допустимые альтернативы и
диагностическую причину каждого отвергаемого варианта. Алгоритм не заполняет
имя ревьюера и не использует LLM как единственного судью. Comparison объявляет
prerequisites. Короткий урок также должен быть написан в lessons.json.

Статусы candidate / structurallyChecked / algorithmicallyChecked /
linguisticallyReviewed различаются. Никаких новых утверждений о профессиональном
ревью нет. Для всего нового корпуса смысловая пригодность пока не подтверждена:
0 лингвистически проверенных контекстов, 0 опубликованных harvested exercises.
Все 526 правил требуют семантического ревью достаточного набора контекстов;
516 дополнительно требуют уроков/практики. Прежние 83 авторских задания сохранены
с прежним editorial eligibility, а не объявлены специалистом проверенными.

Список дефицитов — coverage-report.json: insufficientRules. Полные пакеты по
уровням — n5/n4/n3/n2/n1-review-packet.json. Список удержанных от оценки привязок —
excluded-from-scoring.json (5 483 usage ID); это привязки-кандидаты, не готовые
упражнения, и не все они утверждаются ошибочными/неоднозначными.

Добавлен Grammar corpus integrity and morphology job. Только GitHub Actions:
повторный Sudachi-разбор, SHA/лицензии/ID, ссылки, spans, реконструкция текста/ruby,
publication-boundary regressions; реальные source/translation IDs и прямые links

Release gate сохранён и усилен требованием пяти семантически проверенных
контекстов на правило; он пока не может пройти. Корпусный отчёт и review packets
сохраняются в grammar-corpus-coverage.

Публичные URLs Tatoeba обновляются еженедельно. Если там уже другой пакет,
проверка не подменяет pinned snapshot: явно падает, требуется сохранённый архив
или осознанный repin с повторной подготовкой. Воспроизводимость извлечённой выборки
обеспечена batch-lock и закреплённым анализатором. Полные архивы хранить вне Git/Bundle.

Обычная локальная generic/platform=iOS сборка успешна. Локальные tests/XCTest/UI/
performance/Simulator не запускались. Подготовка реального корпуса через Sudachi
не является запуском тестовых сценариев. Результаты нового Actions не объявляются
прошедшими; по просьбе пользователя завершения запуска не ждём.
