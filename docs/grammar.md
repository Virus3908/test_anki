# Обучение грамматике

Все 526 исходных правил и 1526 примеров OpenJLPT сохранены без изменения ID,
японского текста, английских полей и pinned snapshot. Уровни: 81/98/101/123/123.
Материал доступен через библиотеку и поиск офлайн. Полный курс пока НЕ готов:
практика подготовлена для десяти правил; остальные 516 остаются материалом для
чтения. PR должен оставаться Draft. Подробности: [отчёт качества](grammar-quality.md).

## Учебный сценарий

Первое знакомство: конструкция, краткий русский смысл, образование и один новый
разобранный пример → «Попробовать» → задания → результат → следующая готовая
конструкция из общей очереди. Дополнительные материалы раскрываются по запросу.
У уже изученного правила теория пропускается; кнопка книги доступна всегда.

Первая практика содержит 4–6 задач, повторение — 2–4, если столько качественных
материалов доступно. Сложность правила определяет ориентир, номер FSRS-попытки
и ID правила — воспроизводимую ротацию. Начальный урок проверяет образование,
контекст, преобразование и самостоятельную сборку. Дополнительные навыки
чередуются; у повторений чередуется и состав основных заданий. После ошибки
или подсказки добавляется другой контекст того же аспекта. Не более двух
дополнительных задач и восьми задач всего. После трёх самостоятельных ответов на образование, контекст и применение
уверенное повторение может завершиться раньше; после предыдущего Again этот
ускоренный выход не используется. При недостатке материала урок
не дополняется фиктивными вопросами. Без заданий успешная оценка невозможна.

Пропуск, контекст, преобразование, исправление ошибки, различение значений,
понимание предложения используют явно заданные допустимые ID. Их может быть
несколько. Сборка использует выбранную последовательность ID и явно заданные
допустимые последовательности; есть лишние формы/смысловые элементы. Свободный ввод используется только для однозначной формы глагола: принимаются
вычисленные японская запись и чтение. Для произвольных предложений свободный
ввод не применяется.
Неизвестные ID и перестановка неправильной формы не засчитываются.

Ошибка сразу показывает правильный ответ и короткое пояснение проверяемого
аспекта. У правильного ответа — короткий результат. Продолжение закреплено
внизу; при смене вопроса скролл возвращается наверх. На результате показаны
счёт, конкретные слабые аспекты и дата следующего повторения.

## Состояние и FSRS

`GrammarPracticeViewModel` — временное состояние одной попытки; общий
`TrainingSessionViewModel` удерживает его при возврате из настройки/теории и
при выходе и повторном входе в ту же незавершённую попытку. Перезапуск процесса
не восстанавливает незавершённые ответы. Нового persistent store нет.
Undo сбрасывает временную попытку и использует прежний ReviewUndo.

`GrammarLessonRating.rating(results:exercises:)`: вес задания равен сложности
(1/2/3); менее 2/3 взвешенных правильных → Again;
иначе ошибки или подсказки → Hard; всё самостоятельно → Good. Easy автоматически
не назначается. Готовая попытка получает максимум одну оценку `grammar:<ruleID>`.
Есть отдельный шлюз сохранения в модели и прежняя защита общей сессии. Ошибка
записи разрешает повторное сохранение; успешная запись не повторяется кнопкой.
Выход до результата не создаёт review log. FSRS-6, параметры, JSON-прогресс,
ключи и остальные режимы не изменялись. Неготовые правила не входят в оцениваемую
очередь; их старый прогресс сохраняется и будет доступен после подготовки материала.

## Авторинг и перевод

`tools/grammar/lessons.json` содержит отдельные явно составленные ситуации,
правильные ответы, диагностические альтернативы, аспект, подсказку, сложность
и разобранную теорию. `author_exercises.py` компилирует материал без случайных
подстановок японских фрагментов. Если урок отсутствует, генератор не подменяет
его вопросами на название конструкции. `generate.py` добавляет материалы к
неизменённым оригиналам; manifest перечисляет недостающие ID.

Русское введение и все инструкции подготовленных задач находятся в Bundle.
Дополнительные английские материалы переводит прежний TranslationViewModel;
дедупликация/кеширование и защита японских фрагментов сохранены. Перевод не
блокирует практику и не является лингвистической проверкой.

## Проверки

Локально разрешены только обычная iOS-сборка, генерация ресурсов и статические
проверки. XCTest, UI-тесты и Simulator локально не запускаются.
GitHub Actions проверяет исходники, воспроизводимость, ключи/форматы/контексты,
учебную полноту и выполняет hosted/UI/package tests. Release-проверка остаётся
красной до подготовки материала для всех 526 правил. Подмена качества количеством
или успешным машинным переводом не допускается.

## Движок и спряжение

GrammarExerciseEngine — чистый Swift-компонент выбора и порядка заданий.
Первое изучение проверяет разные действия; повторение выбирает образование,
контекст и применение. После Again сложность снова начинается с базовой;
после Hard рост ограничен вторым уровнем. Выбор вариантов не зависит от их позиции.
GrammarAnswerValidator проверяет только явно поддержанные ответы.

GrammarConjugationEngine требует VerbClass, чтение и permittedForms.
Поддержаны Ichidan, девять Godan-классов, 行く, する/составные, 来る/составные,
ある и ограниченный список почтительных глаголов. Формы: основа, ます, て, た,
ない, потенциальная, пассив, каузатив, ば, たら и желание. 不明-класс не угадывается.
Для ある отвергаются потенциальная/пассив/каузатив/желание, отрицание — ない.
Кандзи и чтение 来る преобразуются отдельно. Разговорное ら抜き не используется.
Указание класса не гарантирует естественность любого предложения: отдельный
шаблон обязан разрешать эту форму для своего контекста.

practice-metadata.json содержит запись для каждого исходного ID: исходные
семантические категории, планируемые и реально доступные механизмы, число
примеров, доступные алгоритмические формы и ограничение готовности. Категории
перенесены из явных тегов OpenJLPT; совпадения подстрок не используются. Это
предварительный план авторинга, который требует проверки для неготовых правил,
а не заявление о полноценной практике всех 526.

## Смешанная тренировка

Основная кнопка колоды открывает GrammarSessionPlanner. Для каждого выбранного
уровня он вызывает существующий TrainingSessionEngine.plan с эффективными
DeckOptions (включая дополнительные разрешения на этот день). Затем объединяет
готовых кандидатов с приоритетом Learning/Relearning, Review, новых/начатых,
сохраняя due-порядок внутри приоритета. Никаких интервалов он не вычисляет.
Сессия ограничена четырьмя правилами, каждое — восемью заданиями максимум.

Выбор области: текущий уровень, несколько отмеченных уровней, новые правила,
повторение изученных либо все изученные уровни. Studied исключает никогда не
показанные правила и по-прежнему использует готовность общей FSRS-очереди;
он не делает произвольное внеплановое повторение всех недавних карточек.
Для каждого уровня используются собственные лимиты/колода, и результаты
пишутся с правильным grammar:nN deckID. Неподготовленные правила не оцениваются.

GrammarMixedSessionViewModel удерживает существующие GrammarPracticeViewModel
каждого правила. Новому правилу сначала показываются краткое объяснение и пример,
а кнопка начала резервирует introduction через прежний firstShownAt. Первое
простое упражнение выполняется до возврата к нему в перемешанной практике.
Начатое, но не завершённое правило после перезапуска снова получает объяснение.

При выборе следующего вопроса исключается предыдущее правило, если есть готовая
альтернатива, затем учитываются давность показа, отложенная помощь, приоритет и
воспроизводимый seed. После ошибки/подсказки правило получает cooldown на два
других ответа; другой контекст того же аспекта берётся из резерва прежней модели.
Если других доступных заданий не хватает, ожидание ослабляется: искусственные
вопросы не добавляются. Один оставшийся активный урок корректно завершается.
Задания в попытке не повторяются. Случайного shuffle правил нет.

Сравнительные задания distinguishMeaning пока исключены из смешанного пула:
их встроенный учебный разбор раскрывает целевую конструкцию и не содержит полного
графа изученных prerequisites. Адресный режим сохраняет этот разбор. В смешанной
сессии используется контекст и применение без заголовка проверяемого правила.
Технический exerciseID в accessibility value доступен только Debug UI-tests,
не раскрывает конструкцию пользователю VoiceOver в обычном приложении.

После каждого завершённого правила общий TrainingSessionViewModel выполняет
одну прежнюю progress.apply → ReviewRepository.save и добавляет прежний ReviewUndo.
Повторное сохранение защищено. Незавершённые правила не получают оценки. Частичный
выход оставляет уже сохранённые результаты и удерживает черновик в памяти; после
перезапуска восстановлены завершённые reviews/firstShownAt, не черновик ответов.
Undo отменяет только последнюю сохранённую оценку и начинает ту попытку заново;
остальные результаты сохраняются. При смене дня старая смешанная попытка закрывается.

## Фуригана и визуальные блоки

GrammarExercise.furigana содержит явные transcriptions для точных текстов: условие,
японская фраза, варианты, объяснение и правильный ответ. Сборка объединяет только
заданные чтения выбранных элементов. FuriganaParser требует точного восстановления
UTF-8; неизвестная/повреждённая разметка безопасно возвращает исходный текст.
FuriganaText — прежний общий renderer, showExampleFurigana — прежний переключатель.
Для tasksReading ruby подавляется; на входе формы 食べる не появляется чтение ответа
食べたい. Чтения составлены явно для авторского корпуса, неоднозначные слова могут
остаться без ruby; они требуют того же экспертного ревью, что и новый контекст.

Значение, формула, пример и разбор теперь отдельные appSurfaceCard. Дополнительная
теория остаётся в DisclosureGroup. На вопросе отделены прогресс, условие, японский
текст, ответ и обратная связь; BottomActionBar закреплён, новый вопрос прокручивается
к началу. Итог смешанной попытки показывает реальные ответы, сохранённые новые/
повторённые правила и темы с ошибками, без внутренних FSRS-показателей.

## Аудит всего корпуса

grammar-audit.json содержит 526 записей: категории, число упражнений и уникальных
контекстов, навыки/типы, явные ключи, алгоритмические формы, ruby и необходимость
авторинга/ревью. Десять уроков/83 задачи — не полный курс. 516 правил всё ещё
требуют практики, все 83 задачи/чтения требуют независимой лингвистической проверки.
Release job остаётся обязательным и красным до устранения пробелов.
