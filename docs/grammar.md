# Грамматика: реализация и незавершённый учебный контент

**Модуль не удовлетворяет полной приёмке русскоязычного курса.**
Все 526 исходных правил доступны офлайн, открываются все пять уровней,
работают поиск и самопроверка с обычным FSRS. Русские уроки и проверенные
упражнения обязательных типов ещё не подготовлены. Ограничения видны
в интерфейсе и проверяются отдельным CI job. См. [отчёт качества](grammar-quality.md).

## Воспроизводимые ресурсы

Пять исходных JSON сохранены без изменений в tools/grammar/upstream.
tools/grammar/snapshot.json закрепляет commit, распределение и SHA-256.
Офлайн-генератор не скачивает плавающий main:

```sh
python3 tools/grammar/generate.py
```

Это разрешённая локальная генерация. Генератор прекращает импорт при
изменении snapshot/количества, повторяющихся ID и отсутствии обязательных
исходных полей. Результат — `kanji_test/Data/Grammar/grammar-n5.json` …
`grammar-n1.json` и grammar-manifest.json. Уникальные имена избегают конфликтов
при копировании в Bundle. Синхронизируемая группа Xcode включает JSON
автоматически; hosted tests загружают все пять ресурсов из Bundle.

Каждый ресурс содержит schemaVersion, metadata и rules. Metadata сохраняет
source, repository, commit, version, license, authors, modifications и sourceSHA256.
Для обновления сначала закрепить новый SHA и исходные файлы, сравнить ID,
уровни/поля, явно обновить snapshot и метаданные, затем адаптации, сгенерировать
ресурсы и дождаться CI. Нельзя молча менять количество или добавлять фиктивные правила.

## Модели и загрузка

GrammarRule сохраняет upstream ID, level, pattern, необязательные reading/romaji,
исходные meaning/formation/notes, examples, tags, необязательные localization,
exercises и relations. GrammarLocalization содержит meaningRU, formationRU,
formationNotesRU, explanationRU, usageNotesRU, typicalErrorsRU и reviewer.
Отсутствие перевода — nil с явным уведомлением, а не пустой русский текст
или автоматически сгенерированное объяснение, объявленное проверенным.

GrammarDataLoader — actor с внедряемыми URL для фикстур. Читает Bundle,
декодирует/проверяет вне MainActor, кеширует уровни, возвращает правила уровня,
правило по ID, категории и связи. Неизвестная версия/повреждённый или неполный
ресурс вызывает ошибку, не успешный пустой массив. Модели Codable/Sendable.
Пользовательское состояние не хранится в ресурсе. Никаких сетевых запросов
OpenJLPT/Tatoeba при загрузке/поиске/тренировке нет; всё работает офлайн.

GrammarCategory точно сопоставляет все 70 исходных тегов русским названиям,
не угадывая категории по конструкции. GrammarRelation различает similarMeaning,
register, contrast, prerequisite и sourceMention. Генератор добавляет только
точные однозначные упоминания `〜конструкции` в английских notes.
sourceMention не означает эквивалентность. Полная классификация связей пока
не подготовлена; ссылка даёт возможность самостоятельно прочитать оба источника.

## Подготовка русских материалов

Генератор поддерживает отдельные `tools/grammar/localization/n5.json` … n1.json:
словари по неизменным upstream ID. Файлы адаптации пока не добавлены.
Запись содержит localization, exampleTranslations (исходное японское
предложение → русский перевод), exercises и необязательные relations.
Запрещены неизвестные ID, частичная локализация, несовпадающие примеры и
менее трёх заданий у адаптированного правила. Перевод не меняет rule ID/SRS key.
Само наличие reviewer не доказывает лингвистическую корректность.

GrammarExercise содержит ID задания/правила, kind, promptRU, варианты с
собственными ID/необязательным feedbackRU, acceptedOptionIDs, explanationRU,
difficulty и reviewer. Правильность определяется ID, не положением кнопки.
Модели поддерживают chooseConstruction, fillBlank, identifyConstruction,
chooseCorrectSentence и transformSentence. **Bundled-заданий этих типов нет.**
Добавление новых заданий не меняет запись прогресса правила.

## Практика и FSRS

Для всех 526 правил доступна открытая самопроверка: объяснить значение/контекст,
вспомнить форму присоединения, перевести настоящий пример и объяснить функцию
конструкции. Затем пользователь открывает исходный ответ. Это не корпус
1578 проверенных тестовых заданий. Свободный ответ не сравнивается строками,
правильность не симулируется нажатием кнопки. Такая практика не заменяет
запрошенные авторские упражнения с правдоподобными distractors.

GrammarExerciseSelection детерминированно перемешивает задания/варианты/примеры
по rule ID и числу FSRS-прохождений. GrammarPracticeViewModel отделяет текущий
проход и результаты от ресурса и SRS. После всего прохода пользователь явно
выбирает Again/Hard/Good/Easy в существующем TrainingRatingBar; автоматического
Easy нет. Одно прохождение — один ответ FSRS. Новое правило сначала показывает
урок; повторение сразу открывает самопроверку, объяснение доступно отдельно.

PracticeMode.grammar, колоды grammar:n5 … grammar:n1, ключи grammar:<upstreamID>.
StudyCardCatalog регистрирует правила; StudyAppViewModel+Grammar запускает
обычный TrainingSessionViewModel. Используются прежние TrainingSessionEngine,
неизменённый StudyScheduler FSRS-6 и ReviewRepository/review-memory.json.
Нет второго планировщика/progress store/persistence. Формат истории и старые
ключи не изменены; миграция/сброс прежнего прогресса не требуются.

Действуют learning/relearning/review, лимиты, дополнительные карточки,
смена дня, Undo, сброс ключей выбранной колоды и существующие настройки.
Свободный выбор соблюдает те же лимиты. Повторение выбирает уже начатые правила,
готовность определяет общий planner. Остаток сегодня считается по todayIDs,
включая ожидающие learning. После завершения можно добавить правила обычным
листом завершения дня. Кастомная бесконечная тренировка грамматики не добавлена.

## Навигация, фуригана, поиск, статистика

Главная → Грамматика → любой N5–N1 → выбор урока или последовательная
тренировка/повторение. Уровни не блокируются. grammarLevel/grammarRule расширяют
StudyNavigation; тренировка идёт поверх стека. Экраны используют AppPalette,
appSurfaceCard и общие кнопки оценок. Формулы/объяснения переносятся и поддерживают
Dynamic Type. GrammarExample.ruby преобразует явные `{漢字|かんじ}` в существующий
FuriganaParser/FuriganaText. UTF-8 предложения проверяется строго. При ошибке
показывается исходный японский текст без угадывания чтений. Переключатель прежний:
StudyPreferences.showExampleFurigana. Совпадение разметки не доказывает чтение.

Поиск уровня фильтрует по категории. Глобальный поиск дополнен грамматикой
без изменения прежней AND-семантики. Индекс готовится вне MainActor один раз;
поиск отменяемый с generation-проверкой, один debounce 250 мс на каждом экране.
Поля: японский, исходные kana/romaji, английское значение, имеющиеся русские поля,
русские/английские категории, JLPT. Поиск «хочу» по русскому значению не обещан
до появления переводов. Результат открывает полный исходный урок и практику.

Статистика использует StudyProgressStore: новые, Learning, Relearning, Review,
due, excluded, план сегодня и прежние scheduleBuckets. Полоса — доля правил
на Review, не процент владения. Статус «изучено хорошо» не придуман; визуальная
интеграция существующего CardMastery пока не завершена.

## Проверки

Все тесты/автоматические проверки ресурсов — только GitHub Actions.
grammar-data проверяет SHA-256, ID/порядок, исходные поля/примеры, JSON,
атрибуцию/связи, ключи заданий и воспроизводимость. grammar-release требует
русские уроки/переводы и три задания для каждого правила, а также обязательные
типы по корпусу. **Сейчас grammar-release должен падать: все 526 правил
не удовлетворяют требованиям русского курса. Проверка не отключена.**

Hosted tests: данные, ошибки, ruby, модели заданий, самопроверка, поиск,
SRS, Undo, persistence, лимиты, день и совместимость. UI tests: пять уровней,
урок, самопроверка, глобальный поиск и ссылка. Прежние три jobs сохранены.
Это не полное покрытие всех запрошенных UI-сценариев. validate_ci.py
явно запрещён вне GitHub Actions. Локально запускались только генератор,
статические проверки и обычная сборка generic/platform=iOS; тесты и Simulator
не запускались. AnkiImport не менялся.
