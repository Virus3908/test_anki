# Фуригана примеров Tatoeba

## Проверенный API (12 октября 2026)

Официальные источники: [OpenAPI](https://api.tatoeba.org/openapi.json),
[руководство миграции v1](https://en.wiki.tatoeba.org/articles/show/api-migration-v1).
OpenAPI разрешает использовать `/unstable` как совместимый префикс для `/v1`.
Поиск остаётся `/unstable/sentences`, с прежними фильтрами японского текста,
английского перевода, владельцев, approved переводов и лицензий
`CC BY 2.0 FR,CC0 1.0`. Добавлен только `include=transcriptions`.

Реальный запрос с фильтрами приложения:

```text
https://api.tatoeba.org/unstable/sentences?lang=jpn&sort=relevance&q=学校&trans:lang=eng&trans:is_orphan=no&trans:is_unapproved=no&is_orphan=no&license=CC%20BY%202.0%20FR,CC0%201.0&showtrans=matching&include=transcriptions&limit=3
```

Сокращённая запись из фактического ответа (не выдуманный формат):

```json
{
  "id": 10756861,
  "text": "学校だよ。",
  "owner": "small_snow",
  "license": "CC BY 2.0 FR",
  "transcriptions": [{
    "script": "Hrkt",
    "text": "[学校|がっ|こう]だよ。",
    "needsReview": false,
    "type": "altscript",
    "html": "<ruby>学<rp>（</rp><rt>がっ</rt><rp>）</rp></ruby><ruby>校<rp>（</rp><rt>こう</rt><rp>）</rp></ruby>だよ。",
    "editor": "small_snow",
    "modified": "2022-04-09T01:53:36+00:00"
  }]
}
```

[Источник #10756861, small_snow, CC BY 2.0 FR](https://tatoeba.org/en/sentences/show/10756861).
В ответе также присутствует английский перевод #5852683, автор CK,
с отдельной лицензией CC BY 2.0 FR. Эти поля не изменены.

Дополнительные реальные наблюдения:

- #11491611, «今日は仕事？», Pfirsichbaeumchen, CC BY 2.0 FR:
  `[今日|きょう]は[仕事|し|ごと]？`. Единственное чтение относится ко всему слову.
- #156449, «私は試合を申し込むつもりだ。», CC BY 2.0 FR:
  `[私|わたし]は[試合|し|あい]を[申|もう]し[込|こ]むつもりだ。`.
  `needsReview: true`, `editor: null`: Tatoeba может отдавать автоматические чтения.
- #11381604 содержит `[Hello|]`: пустое чтение допустимо и не добавляет фуригану.
- `GET /unstable/sentences/10756861` без include не возвращает поле transcriptions.
- `GET /unstable/sentences/5852683?include=transcriptions` возвращает
  `transcriptions: []` (английское предложение). В проверенной выборке японских
  предложений пустой массив не найден; это не гарантия доступности чтений во всём корпусе.
- #3480287, «こんにちは！», CC BY 2.0 FR: транскрипция есть, но равна исходному
  тексту и не содержит разметки чтений. UI показывает обычный текст.

## Данные и разбор

`TatoebaTranscription` сохраняет все фактически наблюдавшиеся поля, включая
editor, modified, needsReview и html. HTML хранится как строка, но не исполняется
и не используется для отрисовки. Опциональное malformed поле transcriptions
не мешает загрузке предложения/перевода.

`ExampleFurigana` хранит исходные транскрипции и дату проверки. `FuriganaParser`
обрабатывает только `Hrkt` / `altscript`:

- `[今日|きょう]` → один сегмент с групповым чтением;
- `[学校|がっ|こう]` → два сегмента, согласно явной разметке Tatoeba;
- `[申|もう]し[込|こ]む` → окуригана остаётся обычным текстом;
- `[Hello|]` → исходное слово без чтения.

Поддерживаются чтения хираганой/катаканой, исходные пробелы, переводы строк,
латиница и пунктуация. При неизвестной/неправильной разметке, неверном числе
чтений или несовпадении восстановленного текста с исходным **по UTF-8 байтам**
всё предложение отображается без фуриганы. Чтения не угадываются по отдельным кандзи.
`needsReview` сохраняется, но не блокирует чтения: они могут быть машинными и ошибочными.

## Отображение и настройки

`FuriganaText` использует SwiftUI + нативный UIView с Core Text, без WebKit
и дополнительных зависимостей. Ширина каждого блока учитывает и базовый текст,
и чтение половинного размера. Обычный текст переносится по графемам; групповое
чтение остаётся над своим словом. Закрывающая японская пунктуация примыкает
к предыдущему блоку. Высота каждой строки резервирует место для чтения.
Размер шрифта масштабируется через `@ScaledMetric`, цвета — `AppPalette`.
Нативный рендерер сообщает фактически занятую ширину текста в пределах
предложенной ширины: кнопка источника остаётся рядом с коротким предложением
и не сдвигается к краю контейнера при появлении фуриганы.
UIView также предоставляет собственный `intrinsicContentSize`; содержимое
настраивается до измерения SwiftUI, включая первый проход и смену предложения.
Повторная настройка неизменённого текста не пересоздаёт Core Text glyphs.
Для патологически длинного неделимого блока используется горизонтальное сжатие;
чтение не разделяется произвольно между кандзи.

Исходное предложение доступно VoiceOver и действию «Копировать предложение».
Обычный Text сохраняет textSelection. Выделение отдельных слов в нативном ruby
пока не поддерживается. Меню источников сохраняет авторов/лицензии предложений
и переводов; редакторы транскрипций добавляются к японскому источнику.

`StudyPreferences.showExampleFurigana` включена по умолчанию и сохраняется
в существующем UserDefaults механизме. Переключение меняет только отрисовку;
сеть, исходные данные и переводы не затрагиваются. Общий `StudyExamplesContent`
покрывает просмотр и тренировку слов и кандзи.

## Совместимый кеш

Существующие `WordExampleCacheRepository` / `KanjiExampleCacheRepository`
и `JSONFileStore` остаются единственным механизмом хранения примеров.
Добавлено опциональное поле `furigana`; записи без него продолжают читаться,
включая legacy japanese/translation поля слов. Кеши и пользовательские данные
не удаляются. Идентичность Tatoeba-примера определяется sentence ID из атрибуции.

При загрузке старых записей выполняется запрос
`/unstable/sentences/{sentenceID}?include=transcriptions`: маршрут получения
по ID необходим, чтобы обновить именно сохранённые предложения, не менять
результаты поиска и не заменить старые переводы. Проверяются ID, исходные байты
текста, автор/лицензия и approved статус. Одновременные запросы одного ID в одной
URLSession объединяются. Результат сохраняется вместе с примерами.

- Успешная проверка, в том числе [] или неподдерживаемая разметка: повторного
  автоматического запроса нет. Явный «Перезапросить примеры» по-прежнему возможен.
- Неудачная проверка, offline или изменённый источник: предложение/перевод
  сохраняются; попытка повторяется не раньше суток при следующей загрузке.
- Встроенные примеры без Tatoeba ID не отправляются в сеть ради чтений.

## Проверка

`kanji_testHostedTests/FuriganaTests.swift`: реальные структуры JSON, parser,
UTF-8 инвариант, старые форматы, round-trip, существующие repositories,
URLProtocol mock, отсутствие повторных запросов, offline/backoff и настройки.
`FuriganaRenderingTests.swift`: нативная раскладка, короткий/длинный текст,
большие шрифты, включение/выключение и отсутствие транскрипции, снимки UIKit.
SwiftUI #Preview содержит короткий/длинный текст и fallback варианты.

По указанию пользователя тесты в этой задаче **не запускаются**. Компиляция
через `build-for-testing` не подтверждает прохождение тестов.
