## Полный пример N5: たい

Кратко: собственное желание совершить действие. Основа ます + たい; отрицание
たくない заранее объяснено. Разбор: 新しい靴を買いたいです — хочу купить новые
туфли; 買い — основа, たいです — желание. После «Попробовать»:

1. 日本へ（　）たいです: 行き / 行く / 行って / 行った.
2. Ситуация: сам хочешь вечером смотреть фильм. 映画を見たいです / 見ました / 見たくないです.
3. 日本語を勉強します → выразить желание: 勉強したいです.
4. Собрать желание купить машину из 車を / 買い / たい / です; исключить 買う, たくない.
5. Один из ротируемых аспектов: исправить 読むたい; различить своё действие и действие друга
   (отличие заранее объяснено); либо понять отрицание 働きたくない.

При ошибке в основе — другой глагол: お茶を（　）たいです, 飲み / 飲む / 飲んで / 飲んだ.
Результат: счёт и «Повтори: Основа ます перед たい», если это было слабым местом.
Всё самостоятельно → одна Good; помощь/умеренные ошибки → Hard; много ошибок → Again.
Следующая готовая конструкция берётся из существующей очереди.

## Полный пример N3: わけではない

Кратко: отрицание вывода/обобщения, а не всякого возможного случая. Обычная форма
+ わけではない; な-прилагательное + な. Разобранный пример: 忙しいからといって、
毎日残業するわけではない — занятость не означает ежедневной сверхурочной работы.

1. 日本人が全員、毎日寿司を食べる（　） → わけではない, не わけだ / はずだ.
2. Иногда читаешь романы, но не каждый день → 毎日小説を読むわけではない.
3. Отвергнуть «всегда легко»: いつも簡単です → いつも簡単なわけではない.
4. Собрать 高い物が / 必ずしも / 良い / わけではない, исключив わけだ.
5–6. Два из трёх: исправить 暇だわけ → 暇なわけ; различить ограничение частоты
   и невозможность (оба смысла объяснены); понять 甘い物が嫌いなわけではない.

При ошибке в な-прилагательном — 静か（　）わけではない с другим словом.
Результат указывает «Границы отрицания» либо форму な-прилагательного, а не даёт
общую лекцию. Теория доступна без потери ответов; повторение начинается практикой.

## Полный пример N1: がてら

Кратко: один выход, два дела. Существительное / основа ます + がてら.
Разбор: 買い物がてら、友達の家に寄った — за покупками, заодно к другу.
Сразу объясняется отличие от одновременного ながら и длительного かたわら.

1. 友達を駅まで（　）がてら、銀行に寄った → 送り.
2. Вышел гулять, заодно отправил письмо → 散歩がてら、郵便局で手紙を出した.
3. Посетил музей, заодно парк → 博物館を見がてら、公園にも寄った.
4. Собрать ジョギング / がてら / 店に / 寄った, исключив союз цели.
5–6. Два из трёх: исправить 帰るがてら → 帰りがてら; различить один выход
   и две длительные деятельности; понять 友達を送りがてら、薬局に寄った.

При ошибке в основе — 先生を（　）がてら、展覧会を見てきた → 訪ね.
Результат выделяет образование или связь двух дел; одна оценка FSRS после попытки.

## Ограничения и следующие обязательные работы

Автоматически создаётся оболочка и provenance, а не японские задания. Статус
`automaticallyChecked` означает проверку структуры, уникальности, ключей и
привязки к источнику. Он НЕ означает проверку естественности, всех допустимых
ответов, нюансов регистра или педагогической эффективности. Reviewer отсутствует.
Все 48 задач требуют экспертного ревью; особенно отрицание N3, уступка N2,
сочетаемость がてら и отвлекающие варианты сравнения. Машинный перевод дополнительных
материалов не меняет этот статус. Контекстно неоднозначный материал должен быть
снят с оценки или получить все допустимые ключи после ревью.

Оставшиеся 520 ID перечислены в grammar-manifest.json и в CI-отчёте pendingRules.
Нужно составить специализированный материал для каждого, включая качественные
русские вводные, новые контексты и резерв повторения. Шесть демонстрационных уроков
не заявляются как готовое покрытие N5–N1. Первоначальный и повторный проходы могут
использовать часть общих задач: в текущем маленьком пуле полностью исключить
повторение контекстов между попытками нельзя. Сборка ограничена явными порядками;
альтернативный грамматически правильный порядок нужно добавить в acceptedOrders.
