# Качество грамматического контента

Источник: OpenJLPT 0.3.0, commit
`0d1d3410bec90bd4098a7c72de820543cb4f707c`.

| Материал | Объём |
| --- | ---: |
| Правила N5 / N4 / N3 / N2 / N1 | 81 / 98 / 101 / 123 / 123 |
| Всего правил / неизменённых исходных японских примеров | 526 / 1526 |
| Правила с минимум тремя заданиями и минимум двумя типами | 526 |
| Выбор конструкции | 1052 |
| Заполнение пропуска | 406 |
| Определение конструкции | 526 |
| Выбор предложения с нужной конструкцией | 455 |
| Преобразование предложения | 1 |
| Всего заданий | 2440 |

По уточнению пользователя русские материалы не входят в Bundle: все 526
английских уроков и 1526 переводов примеров переводятся на телефоне существующим
системным переводчиком, как кандзи. Переводы кешируются в прежнем TranslationStore.
Наличие исходников для перевода не означает, что каждый пользователь уже получил
все русские переводы; без языковой модели и кеша показывается оригинал.

Задания воспроизводимо создаются `author_exercises.py` из pinned snapshot.
Происхождение содержит commit, rule ID, индекс примера и метод составления.
Статус `automaticallyChecked` означает проверку соответствия источнику,
идентичности вариантов и ключей, буквального восстановления пропуска, а не
экспертную лингвистическую проверку. Reviewer не выдумывается и не заполняется.
Статусы draft / automaticallyChecked / linguisticallyReviewed разделены в модели.

Выбор значения и формулы проверяет сопоставление с исходным правилом;
определение конструкции использует реальный пример и его исходный перевод.
Для выбора употребления все предложения грамматически корректны: требуется
выбрать предложение с заданной конструкцией. Чужие примеры консервативно
исключаются при наличии фрагмента проверяемого паттерна. Это не упражнение
«три неправильных японских предложения и одно правильное».
Пропуски восстанавливают точный исходный пример; варианты взяты из настоящих
других конструкций, а не случайного изменения японских символов.
Преобразование たい явно составлено: варианты выражают желание, прошедший факт,
отрицание и отрицание в прошлом; правильный ответ совпадает с примером источника.

Ограничения: ручное ревью всего корпуса не проводилось. Автоматическая
фильтрация не доказывает отсутствие всех семантических пересечений, особенно
N2/N1. Значительная часть заданий проверяет узнавание и связь с примером,
а не свободное порождение речи. Для двух N4 правил без notes (ずつ, 目)
добавлены отдельные английские пояснения в авторинге; исходные notes не меняются.
Разбор distractors не объявляет другие настоящие конструкции ошибочными вообще.

Системный перевод может ошибаться в терминологии/нюансах. Есть английский
оригинал и повторный перевод. Японские фрагменты защищены маркерами; при
повреждении маркеров возвращается оригинал, а не изменённая формула.
Фуригана берётся только из исходника с точным восстановлением текста;
это не ручная проверка неоднозначных чтений. sourceMention не означает
эквивалентность конструкций.

CI сохраняет `grammar-quality.json`, проверяет 526/1526 исходных записей,
минимум три задания/два типа для каждого правила, четыре уникальных варианта,
все пять типов по корпусу, реальные ссылки и источник ключей. Grammar Russian
content readiness сохранён; по уточнённому требованию он проверяет английскую
основу для перевода на устройстве вместо несуществующего bundled русского курса.
Порог упражнений не уменьшен. Проверки выполняются только GitHub Actions.
Скриншоты из UI-тестов публикуются для отдельного визуального ревью; прохождение
тестов само по себе не подтверждает идеальный дизайн или лингвистическое качество.
